[글 본문 목차 - 가장 중요]
- 사용자가 원하는 것: 목차를 글 안에 넣지 말고 "본문 왼쪽 바깥"으로 빼서,
  스크롤하면 글을 따라오게(sticky). 왼쪽 빈 공간을 목차가 채워주는 모양.
  - 2026-08-29 사용자: "목차도 옆으로 포스팅 내용중에 들어가는게 아니라 옆에다가
    빼버리고 글을 따라오는식으로 만들면 좋을거같고"
  - 2026-08-29 사용자: "왼쪽은 목차가 글 옆에 붙어서 빈 부분을 매꿔주는데"
    (왼쪽 목차는 마음에 들어 함)
  - 2026-08-30 목차를 오른쪽 float로 바꿨더니 사용자: "왼쪽 목차 어디갔냐고"
    → 오른쪽 방식은 원하지 않음.
- 지금 사이트 "추가 CSS"에 들어간 것 = 왼쪽 따라오는 목차 버전
  (design/post-dark-theme.css가 그 원본. 1600px 이상 넓은 화면에서 position:sticky +
  float:left + margin-left -266px).

[실수 기록 - 반복 금지]
- 2026-10-29에 "목차가 사라지는 버그를 고친다"며 저장소 CSS를 오른쪽 float 버전으로
  바꿨는데, 이건 사용자가 이미 싫다고 한 방식이었음. 2026-10-30에 사용자가 붙여넣어보고
  "목차 따라오는게 이상하게 붙어서" 예전 것 유지 → 저장소도 원본(왼쪽)으로 되돌림.
- 교훈: 목차 위치를 바꾸기 전에 이 파일의 사용자 요구부터 확인. 위치를 바꿔야 할 이유가
  생기면 먼저 사용자에게 묻고, 넓은/좁은 화면 캡처로 비교해서 보여준 뒤 진행.
- 왼쪽 목차의 알려진 약점: 화면이 1600px보다 좁으면 목차가 글 안 카드로 돌아감.
  워드프레스가 본문에 margin-left/right:auto !important를 거는 화면에서는 목차가 안 보일
  수 있음(예전에 한 번 겪음). 고칠 때도 "왼쪽 + 따라오기"는 유지한 채로 고칠 것.

[페이지 HTML 붙여넣기 주의]
- 워드프레스 HTML 블록이 저장할 때 코드 속 '&' 기호를 '&#038;'로 바꿈 → 코드가 멈춤.
  그래서 페이지 HTML의 스크립트는 text/plain 상자 + 기호를 되돌려 실행하는 짧은 실행부
  구조로 되어 있음. 이 구조를 없애지 말 것.
- 페이지끼리는 "페이지 제목"으로 서로 찾음 (ETF, TREND, PATENTS, BIO, ENERGY, SOCIETY,
  허브는 Insights). 제목을 바꾸면 탭 연결이 끊길 수 있음.

[글 이미지 (media_engine.py) - 2026-10-30 사용자 확인한 시안]
- 대표 이미지 카드(1200x630): 남색 그라데이션 배경, 금색 짧은 선 + 분야 영문명(금색),
  제목(흰색 큰 글씨), 아래 "DATA-DRIVEN INSIGHTS · ondo99.com", 오른쪽 아래 흐린 선 그래프 장식.
  이모지 없음.
- ComfyUI 그림 썸네일: 사용자가 텔레그램으로 보낸 그림을 배경으로, 왼쪽 45%를 남색으로 진하게 덮고
  오른쪽으로 갈수록 그림이 드러나게 한 뒤 같은 글씨 배치를 얹음. 프롬프트도 "남색·금색 톤, 주제는
  오른쪽, 왼쪽은 비워두기, 글씨·로고·실제 인물 없음"으로 고정(media_engine.IMAGE_STYLE).
- 데이터 차트: 남색 배경, 금색 선/막대(최신 값만 금색 강조), 아래에 자료 출처 + ondo99.com.
- 사진: Unsplash. 사진 아래 사진가 이름·Unsplash 링크 필수(규칙).
- 절제 규칙 (사용자 요청: "중구난방으로 들어가면 정신없으니 필요할 때만"):
  한 글에 사진 최대 1장(도입부 끝), 차트 최대 1개(본문 중간), ComfyUI 본문 그림 최대 2장,
  표는 Part3에 1개만. 숫자 자료가 없는 글은 차트 없음, 점이 2개뿐이면 차트 안 그림.
  ETF 종목 분석 글은 자체 차트가 있어 사진·본문 그림 없이 대표 이미지 카드만.
- 배치 규칙 (사용자 요청: "표 사이에 들어가거나 이상하게 말고, 문단이 끝나는 지점에 적절하게"):
  이미지는 대제목(<h3>) 바로 앞, 즉 앞 단락이 완전히 끝난 자리에만. 문단 중간·표 안·목록 안 금지.
  앞이 표/이미지로 끝나는 자리 금지, 앞 단락 250자 미만이면 금지, 한 자리에 하나.
  본문 그림은 다른 이미지와 사이에 단락이 하나 이상 있을 때만. (media_engine.plan_layout)
