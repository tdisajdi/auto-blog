=================================================================
 Threads(쓰레드) 홍보 계정 연결 안내 (2026-11-21)
=================================================================

★ 중요: 아래에서 받는 값(열쇠·번호)은 저장소(git)에 파일로 올리면 안 됩니다.
  이 저장소는 공개라서 누구나 볼 수 있습니다.
  워드프레스 열쇠(WP_OAUTH_TOKEN)를 넣은 곳과 같은 곳 - GitHub 비밀값 'DOTENV_CONTENTS' - 에
  줄을 두 개 더하면 됩니다. (이 안내 파일 자체에는 비밀값이 없습니다.)

-----------------------------------------------------------------
[1] Meta 개발자 앱 만들기 (처음 한 번)
-----------------------------------------------------------------
1. https://developers.facebook.com 에 페이스북 계정으로 로그인 → 오른쪽 위 '내 앱' → '앱 만들기'
2. 앱 이름: 예) ondo-threads  /  연락 이메일: 본인 이메일
3. '사용 사례'에서 'Threads API 사용(Access the Threads API)'을 고름 → 다음 → 만들기
   (회사·비즈니스 연결을 물으면 '나중에' 또는 '연결 안 함'으로 넘어가도 됨)

-----------------------------------------------------------------
[2] 권한 켜기 + 내 Threads 계정을 테스터로 넣기
-----------------------------------------------------------------
1. 앱 화면 왼쪽 '사용 사례' → 'Threads API 사용' → '맞춤 설정(Customize)'
2. 권한 목록에서 아래 두 개가 '추가됨'인지 확인 (없으면 '추가')
     - threads_basic
     - threads_content_publish   ← 글 올리기에 꼭 필요
3. 같은 화면(또는 '앱 역할' → '역할')에서 'Threads 테스터 추가' → 홍보에 쓸 Threads 계정 이름 입력
4. Threads 앱(휴대폰) 또는 threads.com → 설정 → 계정 → 웹사이트 권한(Website permissions)
   → '초대(Invites)'에서 방금 앱의 초대를 '수락'
   ※ 내 계정에만 올리는 것이라 Meta의 앱 심사는 필요 없습니다.

-----------------------------------------------------------------
[3] 열쇠(액세스 토큰) 받기
-----------------------------------------------------------------
1. 다시 '사용 사례' → 'Threads API 사용' → '설정(Settings)'
2. 아래쪽 '사용자 토큰 생성기(User Token Generator)'에서 테스터로 넣은 계정 옆 '액세스 토큰 생성'
   → 로그인·허용 → 긴 글자열(열쇠)이 나옴. 이것을 복사.
   ※ 화면에 '60일(long-lived)'이라고 나오면 그대로 쓰면 됩니다.
     '1시간'짜리라고 나오면, 같은 화면의 '앱 시크릿 코드'도 함께 적어 두세요(아래 [4]의 선택 줄).
     Claude가 첫 실행 때 60일짜리로 바꿉니다.
3. 받은 날짜를 적어 둡니다(60일 뒤 만료 - Claude가 10일 전에 텔레그램으로 알려 드립니다).

-----------------------------------------------------------------
[4] GitHub 비밀값에 넣기 (워드프레스와 같은 곳)
-----------------------------------------------------------------
1. GitHub 저장소 → Settings → Secrets and variables → Actions
2. 'DOTENV_CONTENTS' 옆 연필(Update) → 지금 내용은 그대로 두고 맨 아래에 아래 줄을 더함:

THREADS_ACCESS_TOKEN=여기에_[3]에서_복사한_열쇠
THREADS_TOKEN_DATE=2026-11-22
# 아래 줄은 [3]에서 '1시간짜리' 열쇠가 나왔을 때만:
THREADS_APP_SECRET=여기에_앱_시크릿_코드

   - '=' 앞뒤에 띄어쓰기 없이, 따옴표 없이
   - THREADS_TOKEN_DATE는 열쇠를 받은 날짜(YYYY-MM-DD)
   - 계정 번호(사용자 ID)는 넣지 않아도 됩니다 - Claude가 열쇠로 알아냅니다
3. 'Update secret'으로 저장

-----------------------------------------------------------------
[5] 끝나면
-----------------------------------------------------------------
Claude에게 "쓰레드 넣었어"라고만 알려 주세요.
Claude가 열쇠가 맞는지 확인하고(계정 이름만 확인, 열쇠 값은 출력하지 않음),
시험 글 1개를 올려 보여 드린 뒤, 블로그 글이 공개될 때마다 자동으로 올리게 켭니다.

자동으로 올리는 글의 규칙:
- 블로그에 공개된 한국어 글만, 공개 몇 시간 뒤, 한 글에 한 번
- 질문 한 줄 + 글에 있는 핵심 숫자 하나 + 링크 (사라·오른다 같은 권유 없음)
- 하루 최대 2개 (블로그 공개 속도와 같음), 댓글 자동 답장은 하지 않음

※ Meta 화면의 메뉴 이름은 바뀔 수 있습니다. 위 이름이 안 보이면 화면을 캡처해 보여 주세요.
참고(공식 문서): https://developers.facebook.com/docs/threads/get-started
                https://developers.facebook.com/documentation/threads/get-started/get-access-tokens-and-permissions
