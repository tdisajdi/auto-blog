- 종목 분석 글: ondo/writing/analysis.py(시각 자료 서랍에서 2~3개 고름, 온도 서명 띠). (옛 5조각 방식은 11-09에 삭제 - git 기록에 있음)

- 통과 직전 확인 채점(11-09): 통과로 나온 판만 한 번 더 채점, 새 치명·중요가 나오면 통과 취소(끄기: CONFIRM_REVIEW=0). 근거: 같은 글 3번 채점 시 치명·중요 7개 중 4개가 매번 안 나옴.
- 부분 고침(11-09): 지적이 모두 본문 문장을 콕 집으면 그 문장만 고쳐 받아 바꿔 넣음(전체 다시 쓰기 대신). 빠진 내용·교열 막힘이 있으면 전체 고쳐쓰기. 끄기: PATCH_MODE=0.
- 제목 답 위치(11-09 밤 바꿈): 도입부 첫 문단에서 먼저, 정리에서는 되풀이 금지(한 줄 정리 예외). 근거: 독자 30초 기준과 옛 규칙의 충돌.
- 남길 판 고르는 순서: 통과 → 교열 막힘 없음 → 치명 적음 → 점수 → 지적 개수(11-09 고침: 전엔 지적 개수가 점수보다 먼저라 0.38점 판이 남기도 함).
- 자동 발행은 꺼져 있음(AUTO_PUBLISH 기본 꺼짐) → 모든 글 임시글.
- 사실 검증 좋은 모델 필수(11-19): 사실 담당이 가벼운 모델로 내려가거나 빠지면 20초 쉬고 좋은 모델로 한 번 더, 그래도 안 되면 통과 취소('통과 보류' 기록, 임시글). 본 검토·확인 검토 둘 다. 쉬는 초: FACT_RETRY_PAUSE.
- 상록 글 공개까지 순서(11-19): 수동 실행(임시글) → tr:export로 받기 → 사람 읽기 → patch:번호 → (필요하면 fact-recheck:번호) → publish-passed:번호 → 영어 번역(보편 주제만) → tr:push.
- 공개 판정 두 길(11-20): ① 자동 편집장 검토 통과 + 그 판 사실 검증이 좋은 모델 ② 자동 검토에 치명·중요 없음 + Claude 고침(lab/patches)이 글에 다 들어감 + 고친 글을 좋은 모델이 다시 검증(lab/recheck, patch_applied=true)해 치명·중요 0개. ②를 쓰려면 patch 뒤에 fact-recheck를 꼭 다시 돌린다.
- 수동 실행은 한 번에 하나씩: 실행 묶음(concurrency)이 기다리는 실행을 1개만 남겨, 연달아 누르면 앞의 대기 실행이 취소됨(11-19 두 번 겪음).
