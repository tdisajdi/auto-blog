# ondo 디자인 규칙 (DESIGN.md)

사이트·썸네일·차트를 고치는 사람(또는 AI)은 이 파일을 먼저 읽는다. 색·글꼴·간격은 여기 적힌 대로.
(2026-11-11 전체 개편. 사용자 원칙: "겉은 도트로 가볍게, 속은 깔끔하고 정확하게" / 가독성을 버리지 않는다)

## 세 층
| 층 | 무엇 | 글꼴 | 도트? |
|---|---|---|---|
| 브랜드 | 로고, 온도계, 분야 아이콘, 라벨(짧은 영어), 구분선, 버튼, 404 | Silkscreen(영어 전용) | O |
| 읽기 | 한국어 제목·본문·목차·표·메뉴 | Pretendard | X |
| 데이터 | 그래프·숫자 | Pretendard(숫자는 tabular-nums) | 색만 |

## 색 (theme/ondo.css :root)
- 남색: --o-navy #10203b, --o-navy-2 #1a2e52, --o-navy-3 #2a4373 (머리·바닥·첫 화면 띠)
- 종이: --o-paper #f7f4ec(바탕), --o-card #fffdf7(상자), --o-line #e3dccb, 글자 --o-ink #18202c
- 온도 5색(차가움→뜨거움): #3d6dff #2bb3c0 #f4c44e #ff8a3d #ec4a37
  - 분야: ETF=파랑, 에너지=주황, 인구사회=청록. 강조·버튼=노랑
- 글 본문은 인라인 스타일이 밝은 바탕 기준 → 읽기 층 바탕은 밝게 유지.

## 도트 그림 규칙
(Threads에서 사용자가 공유한 codixel 스킬(MIT, github.com/mankidev/codixel)의 원칙을 옮김 - 스킬 코드 자체는 설치하지 않음)
- 단순한 물건(온도계·아이콘)은 코드로 직접. 복잡한 대상(캐릭터 등)은 참고 그림부터 시작.
- 색 단계는 밝기만이 아니라 색상도 함께 움직이게: 어두운 쪽은 보라·파랑 쪽, 밝은 쪽은 주황·노랑 쪽
  (예: 수은 #a8263a → #e2412f → #ff8a4c → #ffd29a). 밝기만 바꾸면 납작하고 죽어 보인다.
- 외곽선은 순검정·순흰색 말고 그림 자체의 단계에서: 빛 받는 왼쪽 위는 밝은 선, 반대쪽은 어두운 선.
- 원본: theme/snippets/thermo.svg (9×20칸). 밝은 바탕용은 theme_push.svg(ink=True)가 색을 바꿔 줌.

## 데이터 페이지(온도판)
- 카드: 종이색 바탕 + 2px 잉크 테두리 + 6px 각진 그림자, 머리띠는 남색에 도트 영어 라벨.
- 1년 범위는 20칸 도트 막대(칸마다 온도 5색 구간, 지금 칸은 테두리). 매끈한 그라데이션 막대는 쓰지 않음(11-12).
- '°' 기호는 도트 글꼴에서 별처럼 보여 읽기 글꼴로.

## 움직임
- 움직이는 효과는 한 화면에 한 곳(첫 화면 온도계 수은)만. prefers-reduced-motion이면 멈춤.
- 게임용 효과 라이브러리(pixelfx 등)는 쓰지 않음 - 읽기 방해·속도(11-11 판단, lab/THINKING.txt).

## 배치
- 글 화면: 왼쪽 따라오는 목차(1100px 이상) / 본문 720px / 옆 위젯. 좁으면 글 안 '핵심 목차' 상자가 목차.
- 휴대폰(390px)에서 가로 넘침 없음 - 바꿀 때마다 site_pages=shot 캡처로 확인.
- 머리말 메뉴는 한국어(읽기 층), 로고·BOARD 버튼만 도트.
