# ondo 코드 안내 - 신문사 부서 구조

| 부서 | 폴더 | 하는 일 |
|---|---|---|
| 설정 | `config.py` | 사이트 이름·색, 분야 목록, 한국 시간 - 여러 부서가 같이 쓰는 값 |
| 취재부 | `sources/` | 자료 모으기 (트렌드, KOSIS, EIA, 뉴스, 가격) |
| 기획부 | `desk/` | 주제 고르기·추천 |
| 편집국 | `writing/` (+ `prompts/` 지침서) | 기획 회의 → 한 번에 쓰기 → 고쳐쓰기 |
| 교열부 | `checks/` | 자동 점검, 편집장 검토, 중복 검사, 편집 기록부 |
| 디자인부 | `media/` | 썸네일, 차트, 사진, ComfyUI 그림 |
| 발행부 | `publish/` | 워드프레스, 검색엔진 알림 |
| 고객창구 | `telegram/` | 추천·승인·메모·그림 받기·알림 |
| 시험실 | `../tests/` | 자동 시험 (깃허브가 코드 바뀔 때마다 실행) |

## 옮기는 순서 (2026-10-31 결정)
1. 뼈대 + 설정 + 시험실 + 실패 알림 ← 지금
2. 새 편집국 (두 번째 글·ETF 가이드부터)
3. 나머지 부서를 하나씩 옮기기 (옮길 때마다 시험 통과 확인)
4. ETF 종목 분석 글도 새 편집국으로

각 부서 폴더의 `__init__.py` 맨 위에 "지금 위치"(아직 옮기기 전 코드가 있는 파일)를 적어 두었다.
