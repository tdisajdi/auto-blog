# 시험실 (tests)

코드를 고칠 때마다 깃허브가 자동으로 여기 있는 시험을 돌린다(`.github/workflows/tests.yml`).
하나라도 실패하면 합치기 전에 알 수 있다.

- `scenarios/` : 가짜 데이터로 흐름 하나를 처음부터 끝까지 돌려보는 시나리오. 파일 하나 = 시나리오 하나.
  - `topic.py` 두 번째 글 추천·승인·발행 / `ack.py` 승인 버튼 반응 / `buttons.py` 그림 위치 버튼
  - `media.py` 썸네일·차트·사진 배치 / `adapt.py` 분야별 발굴 / `expl.py` ETF 가이드 글
  - `img2.py` 텔레그램 점검 흐름 / `fix.py` 에너지 제목·전송 실패·Gemini 400·KOSIS 표
  - `guides.py` 기초 가이드 계산(총보수·레버리지·적립식·낙폭·배당성장·커버드콜·환헤지)
- 새 오류를 고칠 때는 그 오류가 다시 생기지 않는지 확인하는 시나리오를 하나 추가한다.
- 진짜 키는 쓰지 않는다. 인터넷이 필요한 부분은 시나리오 안에서 가짜로 바꿔 끼운다.

직접 돌리기: `pip install pytest` 후 저장소 맨 위에서 `pytest -q`

- 시나리오 파일을 저장소 폴더에서 직접 돌리지 말 것(`python tests/scenarios/x.py .`): 가짜 기록·상태 파일이 저장소에 생겨
  커밋에 섞인다(2026-11-06 실제로 일어남). 하나만 보고 싶으면 `pytest -q tests/test_scenarios.py -k 이름`(임시 폴더에서 돌아감).
